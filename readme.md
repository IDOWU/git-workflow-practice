# Team Config Dashboard

A web dashboard for displaying team configuration.

## Run locally

Open index2.html in a web browser.

## Main files

- index2.html: Dashboard page.
- readme.md: Project documentation.

## Contributing

1. Create a branch from main for your task.
2. Make and check your changes.
3. Stage and commit the relevant files.
4. Push your branch to GitHub.
5. Open a pull request targeting main.
